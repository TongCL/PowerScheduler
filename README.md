# 定时开关机助手

一款深色风格的 Windows 桌面小工具，可以给电脑设置「定时关机 / 休眠」和「定时开机（唤醒）」，随时可以一键取消。

所有任务通过 Windows 自带的「任务计划程序」执行，**关闭本程序后依然有效**。

## 功能特性

- ⏻ **定时关机 / 休眠**：支持一次性、每天、工作日三种重复方式，可勾选「强制关机」
- ⏰ **定时开机（唤醒）**：让 Windows 在指定时间从睡眠 / 休眠中唤醒电脑
- 🔔 **执行前提醒**：关机前 1 分钟弹出提醒窗口，可选择「知道了」/「延迟 15 分钟」/「取消关机」
- ⏳ **倒计时显示**：设置成功后卡片底部实时显示剩余时间
- 🔄 **任务自动检测**：重新打开程序会自动读取任务计划程序中已设置的任务

## 快速上手

1. 双击 `dist/定时开关机助手.exe` 打开程序
2. 在卡片上选择重复方式和时间
3. 点「设置定时」，在弹窗里确认即可
4. 想取消时，点同一张卡片上的「取消定时」

## 从源码运行

需要 Python 3.11+：

```bash
pip install -r requirements.txt
python app.py
```

## 打包 exe

```bash
pyinstaller 定时开关机助手.spec
```

## 注意事项

- 「定时开机」仅对**睡眠 / 休眠**状态生效；若电脑完全关机，需在主板 BIOS 中开启 RTC 唤醒
- 若唤醒不生效，请检查：控制面板 → 电源选项 → 允许唤醒定时器 → 设为「启用」
- 彻底删除任务：在程序内点「取消定时」，或在「任务计划程序」中删除 `PowerScheduler_` 开头的任务
- 提示「休眠未开启」时，可用管理员模式一键开启，或手动运行 `powercfg /h on`
