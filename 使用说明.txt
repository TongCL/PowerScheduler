        定时开关机助手  v1.1.1  使用说明
══════════════════════════════════════════════

【软件简介】
一款深色风格的桌面小工具，可以给电脑设置「定时关机 / 休眠」
和「定时开机（唤醒）」，随时可以一键取消。
所有任务通过 Windows 自带的「任务计划程序」执行，
关闭本程序后依然有效。

【快速上手】
1. 双击「定时开关机助手」打开程序
2. 在卡片上选择：重复方式（一次性 / 每天 / 工作日）和时间
3. 点「设置定时」，在弹窗里确认即可
4. 想取消时，点同一张卡片上的「取消定时」

【定时关机卡片】
· 执行方式可选「关机」或「休眠」
· 「强制关机」勾选后到点直接断电，不保存文件（慎用）
· 设置成功后卡片底部会显示倒计时
· 执行前 1 分钟会自动弹出提醒窗口（即使本程序没开也会弹），
  窗口里有三个按钮：
  - 「知道了」：关闭提醒，倒计时结束后照常关机
  - 「延迟 15 分钟」：本次关机推迟 15 分钟执行
    （每天/工作日任务只推迟本次，之后的日程不变）
  - 「取消关机」：彻底删除本次定时关机任务
  直接关闭提醒窗口 = 照常执行；回车键 = 知道了

【定时开机（唤醒）卡片】
· 原理：让 Windows 在指定时间把电脑从「睡眠 / 休眠」中唤醒
· 注意事项：
  1) 电脑处于 睡眠/休眠 状态时才能被唤醒；
     若电脑「完全关机」，需要在主板 BIOS 里开启 RTC 唤醒
  2) 若唤醒不生效，请检查：
     控制面板 → 电源选项 → 更改计划设置 → 更改高级电源设置
     → 睡眠 → 允许唤醒定时器 → 设为「启用」
  3) 唤醒后电脑停在登录界面，输入密码即可使用

【常见问题】
Q：关了程序，定时会失效吗？
A：不会。任务由 Windows 任务计划程序执行，重新打开本程序
   会自动检测并显示已设置的任务。

Q：怎么彻底删除任务？
A：在本程序里点「取消定时」，或在「任务计划程序」里删除
   名为 PowerScheduler_ 开头的任务（关机 / 提醒 / 延迟 / 唤醒）。

Q：延迟后卡片显示「已暂停」？
A：这是正常状态——延迟期间循环任务被暂时挂起，到点会自动
   恢复并执行关机；也可随时「取消定时」或重新设置。

Q：提示「休眠未开启」？
A：管理员模式下，点击关机卡片里的橙色提示可一键开启休眠，
   或手动运行命令：powercfg /h on
